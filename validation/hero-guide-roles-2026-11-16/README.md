# 棋子职业与出装方向修正审计

日期：2026-11-16。全量190条为程序核对及前后差异，不代表每项建议都经过人工实战验证。15个具体英雄技能实例完成回归。

## 根因与修复

- 官方职业/特质映射没有模式内ID碰撞；原生成器丢弃了kind，UI又将推断出装方向突出展示，容易把推断误当职业。已保留kind与职业状态。
- 已证实的算法错误是先按狙神、枪手、裁决战士等名称判物理，再看技能。橘提莫、克格莫、吉格斯因此得到错误的物理装备方向。
- 技能伤害类型、加成类型、普攻模式与承伤/辅助分工现分开保存。法术加成不自动等于魔法伤害，魔法伤害也不自动等于纯法强出装。
- 歧义或技能/官方出装冲突时暂停泛用三件套与泛用纹章，保留官方实例、历史观察与直接技能触发证据。
- 原始配置缺失的482/483只显示待核验ID；0/-1明确区分无常规职业。
- 无蓝条被动英雄排除以回蓝为核心的纳什之牙、常规回蓝装、魔蕴与施法收益纹章。
- 眩晕/晕眩需判断自身施加，友军获得护盾不当作自身护盾；伊莉丝/杰斯反例已覆盖。
- 开发复核绑定当前模式官方英雄源文件SHA256；快照变化时旧复核不生效，回退待核验。
